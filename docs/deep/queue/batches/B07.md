## Foundation-correction lane (appended after the B06 review; ADR-032)

### VSF-B07-T09 · Execution consumes only Validated<T> minted by Rust validation (F8 finding)

- **Depends:** VSF-B06-T08
- **Scope:** backend/ir; frontend/packages/ir; frontend/packages/wasm-host; backend/execution
- **Done when:** Go and TypeScript decoders return Unvalidated values; only the Rust validation report (native worker or WASM) mints Validated, and execution accepts nothing else.
- **Positive:** a contract decoded in Go and in TypeScript is validated through Rust and then executes
- **Adversarial:** an active contract with effect_understated, witness_not_applicable or write_without_verification decoded in Go or TS is refused by the executor
- **Evidence:** docs/deep/evidence run logs plus a task receipt

### VSF-B07-T10 · Browser fixtures resolve the complete module graph and report load failures (wasm-browser finding)

- **Depends:** VSF-B07-T09
- **Scope:** fixtures/source-apps; tests/e2e
- **Contract:** fixture server import maps and mounts cover transitive package exports
- **Done when:** The WASM smoke and bench pages resolve every bare specifier reachable through package exports, and a failed import, request or asset status fails the test with its cause instead of a timeout.
- **Positive:** the WASM smoke page reaches status ok in Chromium with @vsf/ir served
- **Adversarial:** a page whose import map omits a transitively imported package fails the server graph test, and the e2e run reports the page error
- **Evidence:** docs/deep/evidence run logs plus a task receipt

### VSF-B07-T11 · Unresolved-write exclusion is atomic with admission to Running (concurrency finding)

- **Depends:** VSF-B07-T10
- **Scope:** backend/execution
- **Contract:** footprint exclusion for session, record and source-global scopes; single-process guarantee only
- **Done when:** No write overlapping an unresolved write reaches the source: the check shares a critical section with the Unknown transition, is repeated after the lock is held, and survives cancellation, journal failure and restart.
- **Positive:** two different request ids queue behind one write that ends ambiguously and the second never contacts the source
- **Adversarial:** barriers with injected ambiguity, cancellation while waiting, journal failure at the Unknown transition, restart, scope-key collisions, cross-scope overlap, race detector
- **Evidence:** docs/deep/evidence run logs plus a task receipt

### VSF-B07-T12 · Reconciliation revalidates authorization and closes only on evidence (reconciliation finding)

- **Depends:** VSF-B07-T11
- **Scope:** backend/execution
- **Contract:** evidence levels proven_committed, proven_not_committed, state_matches_unproven, inconclusive
- **Done when:** Reconciliation re-authorizes through the Rust boundary, refuses other sources, principals and revoked or expired sessions, records every attempt, and moves out of Unknown only on a receipt that proves commit or non-commit.
- **Positive:** a receipt-backed disconnect reconciles to Verified or Failed and releases the exclusion
- **Adversarial:** identical values from another actor, stale reads, unchanged or non-monotonic versions, a receipt for another request, an executor overclaiming its capability, revoked or expired sessions, a changed environment
- **Evidence:** docs/deep/evidence run logs plus a task receipt

### VSF-B07-T13 · Execution-boundary review corrections (adjacent findings)

- **Depends:** VSF-B07-T12
- **Scope:** backend/execution
- **Contract:** late authorization gate, authoritative-status capability, journal repair, actionable browser controls
- **Done when:** Authorization is repeated immediately before the effect against the admitted environment, source statuses that are not authoritative are not taken as proof of no effect, the journal survives a torn tail and oversized details, and the browser presses only usable controls.
- **Positive:** a write whose session lapses during the source read never reaches the source
- **Adversarial:** expired or revoked session, swapped runtime or capabilities, unproven throttle, torn journal tail, oversized detail, hidden, disabled or covered submit control
- **Evidence:** docs/deep/evidence run logs plus a task receipt
