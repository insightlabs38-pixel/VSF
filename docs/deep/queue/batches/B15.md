### VSF-B15-T06 · Scope decoded-contract caches to the calling principal before multi-tenant hosting

- **Depends:** VSF-B15-T05; status `TODO` (not started).
- **Implementation:** Scope decoded-contract caches to the calling principal before multi-tenant hosting.
- **Done when:** A cache hit on a contract document is observable only to the principal that supplied it; one caller cannot learn by timing or memory that another used the same document.
- **Rationale:** The decoded-contract cache in backend/execution is process-wide and keyed by content only, so on a shared runtime a hit tells a caller that another caller used the same document. Found by B13 (ADR-038). Appended by B13 (ADR-038).
