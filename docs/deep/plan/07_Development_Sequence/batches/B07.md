# B07: Implement verified deterministic execution

**Category:** task-level foundational batch  
**Dependencies:** B05,B06  
**Goal:** Operation lifecycle and effects-aware runtime; sources remain authoritative, no false success. Add source adapter/transport interfaces.

## Execution steps

1. Implement prepared/admitted/running/verified/failed/unknown states.
2. Bind VSF caller, source session, environment and exact contract.
3. Add preconditions, source-read freshness check, confirmation propagation.
4. Implement browser executor and mock documented API executor.
5. Implement safe retry policy requiring evidence of idempotency.
6. Provide long-task handle, cancellation and progress events.
7. Add session-scoped locks and basic rate-limit adaptation.
8. Inject crash/timeout after remote commit and record UNKNOWN_COMMIT.

## Concrete artifacts

- Code, scripts, or schemas in the relevant modules with tests and pinned fixtures; versioned documentation and an evidence bundle under the batch ID.
- An explicit compatibility/security/performance delta report. Report unsupported cases, unknown outcomes, and changes to source permissions.
- A change log linking primitive/IR/contract versions and the effective source-app fixture versions.

## Acceptance and evidence

Both direct API and browser plan complete a verified fixture; ambiguous write never automatically retries; denied caller cannot mutate source.

For each completed step record: test command, fixture set, expected behavior, actual behavior, performance measurements when relevant, dependency/IR change list, and rollback procedure. A passing demo alone does not close the batch.

## Stop or redirect criteria

If source effect unobservable, expose raw interaction or preservation only.

## Batch completion handoff

Produce a single concise report with the source revision, repository commit, added/changed primitive IDs, validated operation contracts, failing/held-out tests, performance delta, security impacts, version/retention impacts, and recommendation to **PROCEED**, **HOLD**, **REVISE**, or **REVERT**.
