# B06: Build presentation compiler and minimal accessible renderer

**Category:** task-level foundational batch  
**Dependencies:** B05  
**Goal:** Render semantics into accessible, customizable neutral UI with correct source-state bindings, responsive layout and preservation fallback.

## Execution steps

1. Define PresentationIR constraints and reusable field/grid/nav/form components.
2. Implement light/dark/system tokens and blue/mint accents; status colors distinct.
3. Add keyboard/focus restoration/ARIA announcements and basic RTL handling.
4. Build keyed incremental rendering and local state subscriptions.
5. Add basic compact/spacious density, navigation and command palette.
6. Preserve source widgets in place/side-by-side when unsupported and permitted.
7. Apply per-source styles without destructive DOM changes.
8. Benchmark pure UI operation responsiveness and memory.

## Concrete artifacts

- Code, scripts, or schemas in the relevant modules with tests and pinned fixtures; versioned documentation and an evidence bundle under the batch ID.
- An explicit compatibility/security/performance delta report. Report unsupported cases, unknown outcomes, and changes to source permissions.
- A change log linking primitive/IR/contract versions and the effective source-app fixture versions.

## Acceptance and evidence

User can switch layouts without changing source effect; screen reader/keyboard conformance for fixtures; unknown editor remains usable via fallback.

For each completed step record: test command, fixture set, expected behavior, actual behavior, performance measurements when relevant, dependency/IR change list, and rollback procedure. A passing demo alone does not close the batch.

## Stop or redirect criteria

Do not write own terminal/3D frameworks at this stage.

## Batch completion handoff

Produce a single concise report with the source revision, repository commit, added/changed primitive IDs, validated operation contracts, failing/held-out tests, performance delta, security impacts, version/retention impacts, and recommendation to **PROCEED**, **HOLD**, **REVISE**, or **REVERT**.
