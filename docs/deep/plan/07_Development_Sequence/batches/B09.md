# B09: Integrate extension and secure local bridge

**Category:** task-level foundational batch  
**Dependencies:** B06,B07,B08  
**Goal:** Deliver end-to-end extension interaction with original source session; separate optional premium localhost bridge design.

## Execution steps

1. Package MV3 executable logic, narrow origin permissions and user activation.
2. Connect browser observation and IR compiler/renderer behind stable message protocol.
3. Implement reconnect/restart after service worker death.
4. Prototype authenticated pairing with native companion.
5. Deny untrusted webpage access to native gateway and exercise DNS-rebinding/CSRF fixture.
6. Bind local worker capability manifest and source identity.
7. Add local encrypted settings and emergency fallback to source UI.
8. Create extension distribution policy checklist and reviewer-friendly architecture.

## Concrete artifacts

- Code, scripts, or schemas in the relevant modules with tests and pinned fixtures; versioned documentation and an evidence bundle under the batch ID.
- An explicit compatibility/security/performance delta report. Report unsupported cases, unknown outcomes, and changes to source permissions.
- A change log linking primitive/IR/contract versions and the effective source-app fixture versions.

## Acceptance and evidence

Install extension, transform two fixtures, perform safe operation, restore source UI; malicious web origin cannot invoke local service; extension complies with review design.

For each completed step record: test command, fixture set, expected behavior, actual behavior, performance measurements when relevant, dependency/IR change list, and rollback procedure. A passing demo alone does not close the batch.

## Stop or redirect criteria

Native pairing should not be confused with permission to source accounts.

## Batch completion handoff

Produce a single concise report with the source revision, repository commit, added/changed primitive IDs, validated operation contracts, failing/held-out tests, performance delta, security impacts, version/retention impacts, and recommendation to **PROCEED**, **HOLD**, **REVISE**, or **REVERT**.

## Research validation additions

Send a larger-than-1MiB artifact through the bridge by bounded chunks or an explicitly paired local endpoint; verify authenticated sender origin, message sequence, digest, denial from untrusted content scripts and safe recovery on connection loss.
