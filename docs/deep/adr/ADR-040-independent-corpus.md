# ADR-040: Independent application corpus and evaluation protocol

Status: accepted (B11-T07). Code: `tests/corpus`, data: `fixtures/corpus`, results: `docs/deep/evidence/VSF-B11`.

## Context
B11 asks for coverage measured on applications nobody on this project wrote. Pages authored beside the recognizer rank the author's assumptions (see the earlier blocker packet). The owner is not required to supply the corpus; public, permissively licensed applications can be run locally.

## Decisions
1. **Sources.** Ten applications from seven template families, all pinned (40-hex git revision or release sha256), licensed (MIT, Apache-2.0, W3C) and run read-only or against disposable local state: W3C ARIA Authoring Practices examples, jQuery UI demos, Choices.js, DataTables, AdminLTE 4, four TodoMVC implementations (React, Lit, jQuery, Svelte) and File Browser. Page states that need interaction are reached with scripted user-level steps recorded in the manifest.
2. **Partitions follow template families.** Applications sharing a template, component library or code base share a family and always share a partition (the manifest validator refuses otherwise): development = apg, jquery-ui, choices; validation = datatables; held-out = adminlte, the four TodoMVC implementations, filebrowser. T01 ranks clusters on development and validation only; "held-out frequency" in the plan text is read as frequency across independent, unseen applications, and the held-out partition is measured only as an aggregate before and after the B11 changes.
3. **Seal.** Held-out annotations were committed with a sha256 per page in `fixtures/corpus/heldout.seal.json` before any recognition change. The seal is procedural plus the commit history, not secrecy: development uses `--partition dev,validation` and the held-out baseline is stored without per-page rows.
4. **Hermetic capture.** Each page is captured with the production observer in Chromium (viewport 1280x800, en-US, UTC, reduced motion). Same-origin requests are served locally; npm CDN files at a pinned version are served from a registry-verified mirror; everything else is blocked and counted. Captures reproduce: 55 of 55 structure digests were identical across four runs, with node ids excluded because a late script can shift them.
5. **Independent ground truth.** Expected structure is written by a separate agent session per batch from a dossier containing only the browser's accessibility tree, the application's name and a short description of what people do there. Annotators were told not to read any recognizer code, output or tests, and each annotation records its dossier digest, annotator id and basis. This is a different process and context from the implementer, not a different human; it is evidence tier 3 (independently annotated), not tier 4. One annotator saw a degraded DataTables capture (its jQuery was not mirrored), and one a scope rule that omitted application controls outside the main landmark; both were redone against corrected inputs.
6. **Metrics, with denominators.** Structural recall of fields, actions and collections; semantic agreement among found units (exact, coarser, unclassified, contradicted); false claims (recognized, usable units contradicted by the annotation); composite structures (dialog, menu, tabs, pagination, bulk selection, file input, date picker, tree, combobox popup, virtual list, sortable columns, filter bar, editable cell, drag and drop) recognized versus annotated; workflow coverage (all needed items found with non-contradicting semantics); unannotated recognized units reported separately and never scored; latency and memory. Executable-operation correctness is reported as not measured until supported workflows are executed against disposable state (T05, T06).
7. **Dropped, not hidden.** AdminLTE's calendar page needs a CDN-generated bundle that cannot be pinned offline; it was dropped and recorded in the manifest.

## Limits
Ten applications are a small public sample and say nothing about production-wide compatibility. Annotators are model sessions; disagreements between two annotators were not measured. Ground truth reflects only the accessibility tree, so controls absent from it are not annotated. Authentication-gated or private applications were not used.
